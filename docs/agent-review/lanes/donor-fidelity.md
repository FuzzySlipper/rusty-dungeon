# Lane: donor fidelity

**One question.** Does ruleset or import behavior that claims Delver donor
precedent match the cited donor, or has "approximate" quietly become
"different game"?

**Basis required for an actionable finding.** A named donor path
(`com/interrupt/...java:line`, jar entry, or `jsonschema/` file) plus the
claim in this repo that contradicts it — in code comments, formulas in
`CombatResolver`/`LevelProgression`/`DelverRuleset`, content schemas, or
docs/gameplay-design.md verdicts. When the repo deliberately diverges, the
finding must show the divergence is *unrecorded*: recorded verdicts in
docs/gameplay-design.md are decisions, not defects.

**Not a finding.** Wanting a closer remake; content flavor (names, themes,
numbers) that this repo authored; divergences already recorded in
docs/gameplay-design.md or README.md; donor behavior outside the recorded
P0/P1 scope; anything without a donor path. A claim without a path is
unverified, not faithful.
