# Data

Small, checked-in reference tables that a person maintains. Nothing here is
generated build output, and nothing here is donor game data (rips stay in
gitignored `local/`; donor research lives in `docs/research/`).

The foundation has no hand-maintained tables yet. When a tuning aid outgrows
`content/delve/tuning/` — for example a chart of donor formula constants with
their source lines for fidelity review — it belongs here, referenced from
docs/gameplay-design.md.
